Entry for the make.fun competition **One Letter for Your Day**
(`u-puan-one-letter-for-your-day-e54e9c36`).

The program writes exactly one letter, A to Z, to `/output/entry.txt`.
That single letter stands for a word describing the day — vivid, funny,
and honest. No word, no gloss, no punctuation: just the letter.

## Run

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
